## Publication

**[POMO+: Leveraging Starting Nodes in POMO for Solving Capacitated Vehicle Routing Problem](https://arxiv.org/abs/2508.08493)**
*S. Jakubicz (first author), J. Wawszczak, K. Kuźniak, P. Gora · arXiv, 2025*

Extended POMO, a state-of-the-art reinforcement learning solver for vehicle routing, with a lightweight attention-based agent that learns to choose starting nodes. The method achieves faster convergence and lower optimality gaps on the CVRPLIB benchmark.
